# こえで つくる がっき

声を録音して、その高さを測り、ドレミファソラシドの8音のWAVに変換する。
Scratch の「音をアップロード」に読ませて、自分の声を楽器にする。

小学校高学年から中学生向けのワークショップ「生成AIとScratchで音楽プログラムを作ろう」の
制作パートで使う。

## 動かす

```sh
uv sync
uv run python -m http.server -d docs 8000
```

`http://localhost:8000/` を開く。`localhost` はセキュアコンテキスト扱いなのでマイクが使える。

## つくり

ブラウザだけで完結する。サーバー処理はなく、録音した声は外に出ない。
配信する JavaScript に外部依存はない。npm パッケージを使っていない。

やっている変換はリサンプリング、つまり再生速度を比率で変えることなので、
ブラウザ標準の Web Audio API で足りる。サンプラーという楽器が昔からやっている方式と同じ。

```
docs/                 GitHub Pages で配信する一式
  pitch.js            YIN法による音程検出
  check.js            音階にできない音を弾く
  audio.js            無音カット・長さそろえ・音量そろえ
  scale.js            8音の生成
  wav.js              16bit PCM の WAV を組み立てる
  recorder.js         マイクから生の波形を取る
  app.js              画面の制御。録音の画面と、聞いて保存する画面の2枚

src/voice_scale/      Python 版。同じ処理を実装してある
tests/                ふるまいと異常系。tests/README.md に読みかたがある
tests/e2e/            実ブラウザでの通し確認とスクリーンショット
```

Python 版は開発用で、配信物には含まれない。役割は3つ。

- アルゴリズムの参照実装。JavaScript 版と同じ値を出すことを `tests/test_js_parity.py` で確認する
- 手元の音源から見本の8音セットをつくる
- 純音を使った精度の検証

## コマンド

```sh
uv run ruff check --fix . && uv run ruff format .
uv run pytest

uv run voice-scale info  素材/にゃー.mp3            # 高さと判定を表示
uv run voice-scale build 素材/にゃー.mp3 -o 見本/   # 8音のWAVを書き出す

npm install && npm test    # 実ブラウザでの通し確認（要 Google Chrome）
```

`npm test` は先にサーバーを立てておく。playwright は動作確認だけに使い、配信物とは関係がない。

## 音づくりの決めごと

| 項目 | 値 | 理由 |
| --- | --- | --- |
| 録音 | 2秒 | 声が出るまでのラグと、最高音が半分に縮むぶんを見込む |
| 素材として使う長さ | 先頭1.0秒 | 最高音で0.5秒を確保するのに必要 |
| 1音の長さ | 0.5秒 | テンポ120の四分音符。8音すべて同じ長さにそろえる |
| 基準のド | C2 〜 C5 | いちばん近いオクターブを選ぶ。上限だけ C5 で止める |
| 出力 | 16bit PCM・モノラル・44100Hz | Scratch がそのまま読める |

**8音の長さをそろえるのは飾りではない。** Scratch の「音を鳴らす」は鳴り終わるまで
次へ進まないので、長さがばらつくとメロディのテンポが崩れる。
リサンプリングは低い音ほど長くなるため、そろえる工程が要る。

**基準のオクターブは下へ制限してはいけない。** 上限を C5 に置くのは、高い声で
最高音が2000Hzを超えて耳に刺さるのを防ぐため。いっぽう下限を C4 で切ると、
大人の低い声（110Hz）が15半音も持ち上げられ、まるで別人の声になる。
いちばん近いオクターブを選べば、変換の比は 0.52〜1.41倍に収まる。

## 音階にできない音

無声音やノイズは声帯が震えていないので波が規則正しくならず、原理的に音程が存在しない。
4つの条件で弾いて、子ども向けの文言を出す。

| 条件 | 閾値 |
| --- | --- |
| 音が小さい | ピーク < 0.01 |
| 音が短い | 長さ < 0.15秒 |
| 音程がない | 有声率 < 50% |
| 音程が動く | ばらつき > 150セント |

ばらつきの閾値は緩めに取ってある。教室で何度も弾かれると子どもが萎縮するので、
原理的に無理なものだけ確実に止め、多少音程が動く程度は通す。

倍音が整数比でない金属音は、音階にはなるが「ド」が本当のドにならない。
単体の楽器としては正しく機能するので弾いていない。
Scratch の「音楽」拡張機能の楽器と重ねたときだけ音がぶつかる。

## Scratch への渡しかた

画面2の「8つ まとめてダウンロード」で8ファイルを保存し、Scratch の「音」タブ →
「音をアップロード」で読み込む。ブラウザが「複数ファイルのダウンロード」を
一度だけ確認してくるので、許可する。

Scratch の音リストに並ぶ順番は、ファイルピッカーの並び順になる。
日本語名はコードポイント順に並ぶので「シ ソ ド ファ ミ ラ レ 高いド」の順になる。
音階順に並べたいときは1つずつ順に読み込む。

## デプロイ

GitHub Pages。Settings の Pages で Source を `main` ブランチの `/docs` にする。
以降は push だけで反映される。CI は要らない。

Service Worker で全ファイルをキャッシュしている。会場の Wi-Fi が細いため、
開始時に一度開いておけば、以降は通信が切れても動く。
